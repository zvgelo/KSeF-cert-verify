# Security Policy

## Zgłaszanie podatności

Zgłoś podatność **prywatnie**: GitHub → zakładka *Security* → *Report a vulnerability* (Private vulnerability reporting).
Nie zakładaj publicznego issue z opisem podatności, kluczem prywatnym, hasłem ani tokenem.

Wspierana jest najnowsza wersja z linii 1.x. Szczegóły modelu bezpieczeństwa: [docs/SECURITY.md](docs/SECURITY.md).

## Zakres i ograniczenia

KSeF CertVerify **nie jest oficjalną aplikacją Ministerstwa Finansów**. Wynik lokalny nie oznacza aktywnego statusu certyfikatu w KSeF
ani potwierdzenia zgodności przez MF. MF nie publikuje CA certyfikatów KSeF – zaufane CA konfiguruje użytkownik.
